# 🦀 AgentCRM

> CRM for AI Agents - File-based, automation-first

## 🎯 Vision

Un CRM conçu pour les AI Agents, pas pour les humains.

## 🚀 Quick Start

```bash
git clone https://github.com/Nadir-DNA/agentcrm.git
cd agentcrm
npm install
cp .env.example .env
npm run dev
```

## 📦 Features

- ✅ File-based storage (NDJSON)
- ✅ Workflow automation (YAML)
- ✅ Multi-company support
- ✅ API integrations (Brevo, Resend, Twilio)
- ✅ SLA tracking
- ✅ Custom fields
